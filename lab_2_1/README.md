# Лабораторная работа 1: «Классы»

##Вариант № 2: «Прогноз Погоды»

## Описание проекта

Реализация включает два основных класса:
- **Класс "Суточный прогноз"** — для управления данными погоды за одни сутки
- **Класс "Прогноз погоды"** — для управления заданного количества суточных прогнозов

Проект разработан с использованием современных стандартов C++ и включает:
- Полную документацию кода
- Модульное тестирование
- Примеры использования
- Поддержку различных операций над метеорологическими данными

---

## Общие требования

1. **Стандарт C++:** Проект использует возможности C++20/C++23
2. **Система сборки:** CMake для кроссплатформенной сборки
3. **Качество кода:**
   - Статический анализ (Clang)
   - Динамический анализ памяти (Valgrind)
   - Строгая проверка на утечки памяти
4. **Структура проекта:** Каждый класс в отдельных файлах `.hpp` и `.cpp`
5. **Тестирование:** Модульные тесты с использованием Google Test

---

## Описание классов

### **Простой класс: Суточный прогноз (DailyForecast)**

**Атрибуты:**
- Дата прогноза
- Температура утром, днём и вечером (в °C)
- Погодное явление (солнечно, облачно, дождь, снег)
- Количество осадков (в мм)

**Методы:**
- Конструктор с полной инициализацией всех параметров
- Конструктор с автоматическим определением погодного явления
- Оператор `+=` для объединения прогнозов за одни сутки
- Расчёт средней температуры за сутки
- Проверка на ошибочность прогноза
- Оператор `<=>` для сравнения по дате прогноза

### **Сложный класс: Прогноз погоды (WeatherForecast)**

**Атрибуты:**
- Вектор суточных прогнозов

**Методы:**
- Конструкторы с различными способами инициализации
- Оператор `+=` для добавления новых прогнозов
- Оператор `[]` для доступа к прогнозам по индексу
- Удаление прогнозов по номеру
- Поиск самого холодного дня за период
- Поиск ближайшего солнечного дня
- Фильтрация ошибочных прогнозов
- Объединение дублирующихся прогнозов
- Сортировка прогнозов по дате
- Получение прогнозов за конкретный месяц

---

## Валидация данных

Прогноз считается ошибочным в следующих случаях:
- Осадки при солнечной или облачной погоде
- Снег при температуре выше 0°C
- Температура за пределами диапазона [-100°, +60°C]
- Количество осадков превышает 1500 мм
